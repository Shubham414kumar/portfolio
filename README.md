# Shubham's Cybersecurity Portfolio 🛡️

A premium, interactive, and high-performance personal portfolio built for cybersecurity engineers, penetration testers, and SOC analysts. 

This portfolio is designed to leave a lasting impression with its cyber-aesthetic, interactive terminal, and smooth animations, while maintaining excellent performance and accessibility.

## ✨ Key Features

- 💻 **Interactive Hacker Terminal:** A fully functional fake terminal built into the hero section. Visitors can type commands like `whoami`, `skills`, `projects`, and `sudo hire-me` to explore the profile.
- 🎬 **Cinematic Ops Simulation:** An animated Matrix rain and SOC dashboard background for a true red-team aesthetic.
- 📜 **Scroll Animations:** Sections gracefully fade-in and slide up as the user scrolls, triggered by Intersection Observers.
- 📝 **Blog & Write-ups Section:** A dedicated area for CTF write-ups, vulnerability research, and security guides with category filtering.
- 📊 **Animated Stats:** Dynamic counter components that count up from 0 when scrolled into view.
- 🌗 **Dark/Light Mode:** Full theming support with smooth transitions.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TanStack Start](https://tanstack.com/start/latest)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/) (Radix UI)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## 🚀 Quick Start

To run this project locally, make sure you have Node.js (v18+) installed.

1. **Clone the repository** (or download the source):
   ```bash
   git clone https://github.com/Shubham414kumar/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173`.

## 📦 Deployment

This project is configured to be easily deployed on platforms like **Netlify**, **Vercel**, or **Cloudflare Pages**.

### Deploying to Netlify
1. Push your code to GitHub.
2. In your Netlify dashboard, click **Add new site** -> **Import an existing project**.
3. Select this GitHub repository.
4. Netlify will auto-detect the settings. Confirm them:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist` (or `.output/public`)
5. Click **Deploy Site**.
